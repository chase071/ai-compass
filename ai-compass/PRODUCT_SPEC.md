# 智航罗盘 (AI Compass) · 简要产品说明书

## 1. 产品概述与 Slogan
* **产品名称**：智航罗盘（AI Compass）
* **定位**：面向高校大学生的 AI 智能个性化进阶路线与竞赛实战导航平台
* **Slogan**：从迷茫到上岸：根据你的专业、基础与目标，量身定制专属 AI 成长路线与实战竞赛

---

## 2. 目标用户画像 (Target Audience)
1. **跨专业/文社科/非计算机专业探索者**：
   * 对大模型与人工智能充满好奇，想参加“互联网+”、“挑战杯”等交叉赛道，但零基础不知从何下手，害怕高深数学推导与复杂环境配置。
2. **理工科/自动化/电信等专业进阶者**：
   * 有一定编程或硬件基础，希望将 AI 技术（如端侧模型、视觉大模型、具身智能）融入本专业实验室科研、发表论文或保研加分。
3. **计算机与软件工程科班求职冲刺者**：
   * 面对铺天盖地的 Agent、RAG 等新技术，急需跳出简单 Demo 套壳，建立工程完备的高价值作品集，冲刺大厂实习与秋招。

---

## 3. 解决的核心问题与痛点 (Problem Statement)
* **痛点一：信息过载与“千人一面”**  
  网络上海量教程和学习路线大多是机械罗列所有技术名词，完全脱离学生的实际背景（如年级、每周可用时间、所学专业）。
* **痛点二：只懂代码或不懂业务的“脱节感”**  
  计算机学生常做缺乏真实业务价值的“套壳玩具”；文科/经管学生有极佳场景洞察，却因不懂技术门槛而无法将想法落地成作品。
* **痛点三：学科竞赛中不知如何科学组队与定位**  
  不知道哪些比赛认可度高、不清楚不同学科背景在同一个 AI 竞赛团队里应该负责什么角色才能让评委眼前一亮。

---

## 4. 核心功能设计 (Core Features)

### 【最有价值的 AI 功能】：多维画像诊断 + 动态交互式成长路径生成
* **为什么非 AI 不可？**  
  传统硬编码问卷或静态网页只能提供死板的规则分支（If-Else），无法权衡学生输入的非结构化意图（例如“下个月有互联网+报名 / 电脑没有独立显卡 / 想做智能体Agent”），无法动态权衡算法思维、工程落地与跨界融合的微妙平衡。
* **AI 介入的工作流**：
  1. **多维特征捕获**：专业大类 + 当前年级 + 编程基础 + 每周可用时间 + 核心目标 + 个性化附言。
  2. **深度推理与结构化约束**：AI 对齐 2026 最新高校学科竞赛排行榜与大模型工程技能树，以标准 JSON Schema 产出：
     * 五维能力现状与潜力雷达诊断；
     * 专属破局定位与严厉避坑指南（针对性指出该背景最容易踩的时间陷阱）；
     * 阶梯式 4 阶段进阶里程碑（破冰、内功、实战、竞赛），每个阶段细化至具体动词任务与攻坚资源；
     * 智能匹配前 3 个最契合的竞赛赛事，并给出团队角色分工建议（如“担任队长主抓场景定义与路演答辩”）。
  3. **交互式闭环管理**：
     * 动态渲染五维雷达图与打卡清单，点击任务实时触发粒子庆祝并持久化至本地存储；
     * 支持一键导出离线 Markdown 格式成长手册；
     * 内置“路线领航员”抽屉式智能助手，支持围绕任意阶段进行个性化追问答疑。

## 5. 产品技术架构与双端体验
* **前端呈现**：HTML5 + Tailwind CSS + Lucide 图标系统，完全响应式布局，手机端单手即可丝滑完成所有测评与浏览。
* **数据可视化**：Chart.js 动态绘制能力雷达图，具备平滑动画与数值自适应。
* **双模式推理**：
  * **开箱即用模式 (Demo Ready)**：内置典型学生高保真画像生成器，评委无需填写任何 API Key，点击即可 1 秒体验完整生成流程；
  * **实时大模型调用模式 (Live Model)**：支持一键接入 OpenAI / DeepSeek / Kimi 等外部大语言模型进行实时推理。
* **零依赖部署**：纯静态 Web 应用设计，无需配置任何 Node 复杂构建环境，支持一键部署到 GitHub Pages / Vercel / Netlify。

---

## 6. 后续改进与演进方向 (Roadmap)
1. **接入知识库检索增强 (RAG)**：接入近 3 年各省高校挑战杯、互联网+、天池竞赛的金奖作品公示库，提供基于真实获奖案例的深度拆解。
2. **AI 队友智能撮合大厅**：根据生成的互补雷达图（如“高算法能力”匹配“高跨界场景能力”），为全校学生智能撮合竞赛搭档。
3. **长期学习追踪与自适应动态重排**：结合学生打卡进度和阶段测评结果，动态调控下一周期的任务难度与时间节点。
